# Portfolio Website

A professional static portfolio website built with HTML, CSS, and JavaScript.

## Features

- Responsive hero section and navigation
- Skills section with progress visualization
- Certificates section for achievement highlights
- Projects section with category filtering and detail modal
- Contact form and polished dark theme styling

## Run locally

Open `index.html` in a browser or use a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
