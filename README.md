# 🌐 Personal Portfolio Website

A modern, responsive, and professional **personal portfolio website** built with **HTML, CSS, and JavaScript**. The website showcases skills, certifications, projects, and contact information through a clean dark-themed interface.

## ✨ Features

* 🎨 **Modern Dark UI** — Clean and professional visual design
* 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices
* 🧭 **Responsive Navigation** — Easy navigation across portfolio sections
* 🚀 **Hero Section** — Professional introduction and personal branding
* 💻 **Skills Showcase** — Visual representation of technical skills and proficiency
* 🏆 **Certificates Section** — Display certifications and achievements
* 📂 **Projects Section** — Showcase projects with detailed information
* 🔎 **Project Filtering** — Filter projects based on categories
* 🪟 **Project Detail Modal** — View additional project information without leaving the page
* 📩 **Contact Form** — Allows visitors to get in touch
* ⚡ **Lightweight & Fast** — Built using vanilla HTML, CSS, and JavaScript with no heavy frameworks

## 🛠️ Technologies Used

| Technology     | Purpose                                           |
| -------------- | ------------------------------------------------- |
| **HTML5**      | Website structure and semantic markup             |
| **CSS3**       | Styling, layouts, animations, and responsiveness  |
| **JavaScript** | Interactivity, filtering, and modal functionality |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### 2. Navigate to the Project

```bash
cd your-repository-name
```

### 3. Run the Website

You can simply open `index.html` in your browser.

Alternatively, run a local development server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
